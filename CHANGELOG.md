# Changelog

## 0.3.1

- Fixed a Battle.net friend's real name showing in the chat box while typing to them.
- Fixed Battle.net friends showing by BattleTag instead of their character for a while after a reload.
- A Battle.net friend's tooltip now says when they're playing.
- The settings window now has the Hear Ye bell, and its checkboxes line up.

## 0.3.0

- Battle.net friends now show by the character they're playing, or their BattleTag, never their real name.
- Added a Hide friends' real names setting, on by default.
- Clicking a conversation no longer opens the chat box, so you keep moving.
- The conversation list now scrolls with the mouse wheel when it doesn't fit.
- Moved the gear button to the left end of the title bar.
- Saved history is now just whispers, party, raid and guild: the last 50 lines, for a day.
- Battle.net history saved by older versions is cleared.
- Fixed Hear Ye lighting up when hovering a quest window or the map on top of it.
- Fixed the conversation list staying scrolled after the window grows.

## 0.2.0

- Added new artwork: logo, icon and banner.
- Redesigned the window to match the game's own, with a title bar, portrait and close button.
- Unread counts now show on red and grey pills.
- Sections in the conversation list can be closed.
- The conversation list can shrink to a compact strip of short names and unread counts.
- The window now places and sizes itself above your action bars and beside your character, at any resolution. Reset position in the gear menu puts it back.
- Game messages now count as unread, so replies like /who results aren't missed.
- Renamed Nearby to Say.
- Guild only shows while you're in a guild.
- Fixed right-clicking a name not opening the player menu.
- Fixed guild messages moving to a Former guild row after a reload.
- Fixed the chat box opening on Say instead of the selected channel after a reload.
- Fixed whispers changing order after a reload.
- Fixed the gear button not showing.

## 0.1.0

- First test version.
- One small window for Nearby, Party, Raid, Guild, channels and whispers, each in its own row with an unread count.
- Uses the game's own chat box, so slash commands, /r, Tab and links work as usual.
- Can replace the default chat window. Turn it on or off in the quick setup, or with /hearye chat.
- Keeps each conversation's unsent text when you switch rows.
- Saves 7 days of history per character.
- Background opacity setting, and fades when the mouse is away, like the default chat.
