# Changelog

## 0.1.0

- First test version.
- One small window for Nearby, Party, Raid, Guild, channels and whispers, each in its own row with an unread count.
- Uses the game's own chat box, so slash commands, /r, Tab and links work as usual.
- Can replace the default chat window. Turn it on or off in the quick setup, or with /hearye chat.
- Keeps each conversation's unsent text when you switch rows.
- Saves 7 days of history per character.
- Background opacity setting, and fades when the mouse is away, like the default chat.
